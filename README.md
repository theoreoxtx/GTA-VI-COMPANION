# GTA VI COMPANION

Unofficial Android companion guide for Grand Theft Auto VI.

Features:
- Starting guide
- Money and economy
- Vehicles
- Wanted system
- Characters
- Location directory
- Controls
- Player tips
- Story and endings
- Cheat database

Built with Kotlin, Android WebView, HTML, CSS and JavaScript.

Game-specific claims are marked for verification. This is not affiliated with Rockstar Games.
